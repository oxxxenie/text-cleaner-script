# Text Preprocessing & Analysis Script

##  О проекте
Небольшой скрипт на Python, который автоматизирует рутину с текстом: убирает лишнюю пунктуацию с помощью регулярных выражений (`re`), считает общую длину и выводит частотность слов. Написан для базовой обработки текстовых данных (NLP).

##  Стек
- Python 3.x
- Модуль `re` (регулярные выражения) — для быстрой фильтрации и очистки текстовых корпусов.

##  Что делает скрипт:
1. Переводит весь текст в нижний регистр.
2. Чистит текст от знаков препинания через регулярные выражения.
3. Токенизирует данные (разбивает на массив отдельных слов).
4. Считает общую статистику и частоту встречаемости каждого слова.
